# gezor_aws_crypto_mode (Resource)

Chooses who manages the key that protects the workspace's data key: Gezor (`platform`) or you (`customer`). Destroying it only removes it from Terraform state and keeps the current mode.

## Example Usage

```terraform
resource "gezor_aws_crypto_mode" "this" {
  mode = "customer"
}
```

## Schema

### Required

- `mode` (String)

### Optional

- `key_material` (String, Sensitive) Base64 customer key to import in `customer` mode. Leave out to have Gezor generate one. Write-only.
- `workspace` (String) Workspace id or slug. Defaults to the provider's `workspace`. Changing it recreates the resource.

- `id` (String) Always `crypto`.
