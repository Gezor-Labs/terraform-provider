# gezor_cluster (Resource)

A Kubernetes cluster registered with Gezor. For your own cluster (`byoc`), run `install_command` on it to install the operator; use `gezor_cluster_install_token` for a fresh token later. Turn on apps with `gezor_cluster_app`.

## Example Usage

```terraform
resource "gezor_cluster" "prod" {
  name        = "prod-eu"
  description = "Production, Frankfurt"
  environment = "production"
  region      = "eu-central-1"
  tags        = ["prod", "eu"]
}

# Run this once on the Kubernetes cluster to install the operator.
output "install_command" {
  value     = gezor_cluster.prod.install_command
  sensitive = true
}
```
