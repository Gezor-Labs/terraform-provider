# gezor_cdc_instance (Resource)

A Change Capture (Kafka Connect) worker group on a cluster. Needs the `connect` app. Remove its connectors before destroying it.

## Example Usage

```terraform
resource "gezor_cdc_instance" "finance" {
  cluster_id  = gezor_cluster.prod.id
  instance_id = "cdc-2"
  name        = "cdc-finance"
  replicas    = 2

  depends_on = [gezor_cluster_app.connect]
}
```
