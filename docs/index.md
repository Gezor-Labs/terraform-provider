# Gezor Provider

The Gezor provider configures [Gezor Cloud](https://gezor.com) with an API token. Everything you can set up in the portal can be managed here, except adding or removing people: invite people and assign their roles in the portal, or map identity provider groups to roles with `gezor_sso_group_mappings`.

## Authentication

1. In the portal, open **Organization → API tokens** and create a service account. Give it a role in every workspace (for example Admin), or pick a role per workspace.
2. Create a token. It is shown once and starts with `gzr_sa_`.
3. Export it as `GEZOR_TOKEN`, or set `token` in the provider block.

Tokens can never manage people, API tokens or service accounts, even with the Admin role. Every change a token makes is recorded in **Settings → Audit** with the service account's name.

## Workspaces

A token works across the whole organization. Each request runs in one workspace:

- the resource's `workspace` argument, if set;
- otherwise the provider's `workspace` (or `GEZOR_WORKSPACE`);
- otherwise the organization's main workspace.

`workspace` accepts a workspace id or slug. Use a provider alias per workspace, or set `workspace` on individual resources.

## Cluster commands

Kafka topics and schema subjects are changed by the Gezor operator running on the cluster. The provider starts the command, then waits for the operator's answer (up to `command_timeout_seconds`, default 300). The cluster must be online, with the matching app turned on.

## Importing

Every resource can be imported. Composite ids use `/`, for example `terraform import gezor_kafka_topic.orders cl_123/orders`. Add `@<workspace>` to import from a workspace other than the provider's default: `terraform import gezor_role.analyst role_123@analytics`.

## Rate limits

Each token can make 600 requests a minute. The provider retries rate-limited and temporarily unavailable requests (`max_retries`, default 4).

## Example Usage

```terraform
terraform {
  required_providers {
    gezor = {
      source  = "gezor-labs/gezor"
      version = "~> 0.1"
    }
  }
}

# Create a token under Organization > API tokens and export it as GEZOR_TOKEN.
provider "gezor" {
  # endpoint  = "https://app.gezor.cloud" # or GEZOR_ENDPOINT
  # token     = var.gezor_token           # or GEZOR_TOKEN
  workspace = "main" # or GEZOR_WORKSPACE; each resource can override it
}

# A second workspace through an alias:
provider "gezor" {
  alias     = "analytics"
  workspace = "analytics"
}
```

## Schema

### Optional

- `command_timeout_seconds` (Number) How long to wait for the cluster operator to finish a command (Kafka topics, schemas). Default 300.
- `endpoint` (String) Gezor Cloud URL. Defaults to `GEZOR_ENDPOINT` or `https://app.gezor.cloud`.
- `max_retries` (Number) Retries for rate-limited or temporarily unavailable requests. Default 4.
- `token` (String, Sensitive) API token (`gzr_sa_...`). Defaults to `GEZOR_TOKEN`.
- `workspace` (String) Default workspace id or slug. Defaults to `GEZOR_WORKSPACE`, then the organization's main workspace. Each resource can override it.
